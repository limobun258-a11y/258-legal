258先生 Privacy Policy｜隱私權政策

Last updated 最後更新：2026-11-18

258先生 is an AI-assisted content account run by its owner, limobun. "258先生 Uploader" is a private desktop tool used only by the owner to upload the owner's own videos to the owner's own accounts on YouTube, Facebook, Instagram, Threads and TikTok. It is not offered to the public.

258先生 是由 limobun 經營、AI 協助的內容帳號。「258先生 Uploader」是只供帳號擁有者本人使用的桌面工具，用來把擁有者自己的影片上傳到擁有者自己的 YouTube、Facebook、Instagram、Threads 和 TikTok 帳號，不對外提供服務。

1. Information we access 我們存取的資料

When the owner authorizes the tool through each platform's official login (OAuth), the tool receives an access token and basic account information (such as account ID and display name) needed to publish videos. It only uses the permissions required to upload and publish content, e.g. YouTube youtube.upload, Facebook Page publishing permissions, and TikTok user.info.basic and video.publish.

擁有者透過各平台官方登入授權後，工具會取得發佈影片所需的存取權杖和基本帳號資料（例如帳號編號、顯示名稱），只使用上傳與發佈內容必要的權限。

2. How we use it 使用方式

The data is used only to upload and publish the owner's videos and captions to the owner's own accounts. We do not read, collect or analyze other users' data, and we do not sell, share or use any data for advertising.

資料只用於把擁有者的影片和文字上傳到擁有者自己的帳號。不讀取、不蒐集其他使用者的資料，也不販售、分享或用於廣告。

3. Storage and security 保存與安全

Access tokens are stored only in a local configuration file on the owner's own computer and are never uploaded to any server operated by us. No data is stored on this website.

存取權杖只存放在擁有者自己電腦上的設定檔，不會上傳到任何我們經營的伺服器。本網站不保存任何資料。

4. Retention and deletion 保留與刪除

The owner can revoke access at any time in each platform's settings (Google Account permissions, Facebook / Instagram business integrations, TikTok "Manage app permissions") and delete the local configuration file, which removes all stored tokens.

擁有者可隨時在各平台設定中撤銷授權，並刪除本機設定檔，即可移除所有保存的權杖。

5. Third-party services 第三方服務

Use of each platform is also governed by its own policies: Google Privacy Policy, YouTube Terms of Service, Meta Privacy Policy, and TikTok Privacy Policy.

使用各平台時，也適用各平台自己的隱私權政策與服務條款。
